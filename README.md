<h1 align="center">HERMES</h1>

<p align="center">An open-source steering tool for IT products.</p>

> [!WARNING]
> **Under active development.** HERMES is being rebuilt here, specification first, from a tool used in production
> elsewhere. There is nothing to install yet.

HERMES will help teams steer their IT products. It keeps the backlog in sync across issue trackers, shares
prioritisation between stakeholders, resolves dependencies between tickets, and forecasts delivery dates
probabilistically.

## Follow the work

- [Specifications](docs/spec/README.md): every behaviour is specified before it is coded, and specs stay in step with
  the code.
- [Code map](https://skohscripts.github.io/hermes/code/): how the code is organised, regenerated on every change.
